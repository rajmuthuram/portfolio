# Muthu Raman K — Portfolio

Personal portfolio site for **Muthu Raman K**, Web Designer & Frontend Developer at Zoho (ManageEngine).

## Stack

- Custom HTML
- `css/style.css`
- `js/main.js`

No third-party CSS/JS frameworks.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

This repo is set up for GitHub Pages — push to `gh-pages` / default branch and enable Pages for the root folder.
